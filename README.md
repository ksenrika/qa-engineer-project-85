# `Тестирование в продакшене`

## Codebattle
**Codebattle** — это интерактивная платформа для соревновательного программирования, где два пользователя соревнуются в решении идентичных задач на разных языках программирования в реальном времени.


## Данный проект имеет следующую структуру:

### 1. requirements
- Содержит все требования к проекту, которые покрывают основной функционал сайта

### 2. test-cases
- Включает тест-кейсы и их описание
- Содержит шаги для выполнения тестов
- Описывает ожидаемые результаты

### 3. testing-report
- Содержит результаты тестирования всех тест-кейсов
- Отображает статус проверки (pass/fail)

### 4. issues
- Содержит ссылки на открытые баг-репорты
- Включает баг-репорты, которые были дополнены комментариями
- Содержит новые созданные баг-репорты
- Используется для отслеживания дефектов и их статуса

### 5. reopened_issues
- Содержит ссылки на issues с неисправленными багами
- Используется для отслеживания закрытых баг-репотов, которые вновь воспроизводятся
